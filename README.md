# EvrikaEdu Platform

Платформа для учителей с каталогом методических приёмов и интерактивными инструментами для урока.

## Возможности

- 📚 **Каталог приёмов** — 98 методических карточек с фильтрами
- 🎯 **Конструктор урока** — создание плана урока из приёмов
- ⏱️ **Таймер урока** — управление этапами урока
- 🎯 **Мишень рефлексии** — анонимные полные ответы или свободные отметки, шаблоны вопросов, результаты CSV/SVG
- 🔊 **Шумометр** — контроль уровня шума в классе
- 🪑 **Рассадка класса** — крупные места, список присутствующих, ряды/островки/П-схема, отмена и файлы JSON без автосохранения

## Технологии

**Backend:**
- Node.js + Express
- JSON-каталог; SQLite используется только архивными скриптами

**Frontend:**
- SvelteKit 3, Svelte 5, Vite 8
- TailwindCSS
- PWA (Progressive Web App)

## Запуск

Нужен Node.js не ниже 22.17. Проверено на 22.23.4, версия закреплена
в `.nvmrc`. При использовании nvm выполните в корне `nvm install && nvm use`.

```bash
# Backend
cd backend
npm ci
npm run dev

# Frontend (в другом терминале)
cd frontend
npm ci
npm run dev
```

## Данные и окружение

Источник каталога: `backend/src/data/cards.json`. Команды `npm run dev` и
`npm run build` во frontend автоматически обновляют его статическую копию.
По умолчанию frontend использует этот каталог. Чтобы подключить API, задайте
`VITE_API_BASE_URL=/api` в `frontend/.env` локально либо полный URL API на сервере.
Локальный Vite перенаправляет `/api` на backend, порт 10000.

Конструктор работает в текущей вкладке без автосохранения. PDF скачивается
на компьютере и телефоне; страницы содержат растровое изображение текста.

## Сборка и проверки

- `cd frontend && npm test` — проверки логики урока, таймера и каталога.
- `cd frontend && npm run build && npm start` — Node-сервер, порт 3000.
- На Vercel адаптер выбирается по `VERCEL`, на Netlify — по `NETLIFY`
  (статическая сборка с `index.html`), для Render и локально — Node.
- Docker frontend: из корня репозитория
  `docker build -f frontend/Dockerfile -t evrika-frontend .`.

API каталога доступно для чтения. Административные запросы требуют
`Authorization: Bearer <ADMIN_API_TOKEN>`; запись JSON-каталога через API
пока не поддерживается и возвращает 405. Без настроенного токена — 503.

Каталог полностью переведён на узбекский (названия, описания и инструкции).
Поиск учитывает разные варианты апострофа в узбекском тексте.

## Конструктор рабочих листов

Раздел `/worksheets`: заголовки, текст, открытые вопросы, текст с пропусками,
части слов, тесты, сопоставление,
таблицы, чек-листы, изображения и разрывы страниц. Шаблоны и подписи доступны
на русском, узбекском и английском. Каждый блок редактируется на панели;
его можно переставить, скопировать или удалить, изменения — отменить.

Листы редактируются в текущей вкладке без автоматического хранения.
Для продолжения работы скачайте проект `.evrika.json` и откройте его в конструкторе.
Серверная синхронизация и совместное редактирование пока не предусмотрены.
Печать использует A4 и системный диалог с сохранением в PDF; отдельно
доступны версия ученика и версия с ответами. Масштаб редактора на печать
не влияет. Слишком высокий блок нужно разделить перед печатью.

## Полный план урока

Конструктор урока включает начало, ОНМ, закрепление, практику и итоги.
На каждом этапе можно записать объяснение учителя, действия учеников,
материалы и длительность. Приёмы из каталога необязательны. Время этапа
включает приёмы, а не прибавляется к ним. Все записи включаются в PDF/DOCX.
Из готового плана можно по желанию открыть конструктор рабочего листа
с темой, предметом и классом урока; заметки учителя не переносятся.
Переход между этими двумя редакторами не сбрасывает введённые данные.
После закрытия или обновления страницы несохранённые в файл данные теряются.

## Повторная проверка и контейнеры

Рабочий API читает карточки и метаданные из JSON в `backend/src/data/`;
SQLite при запуске не создаётся и не изменяется. Старые SQLite-импортирующие
скрипты сохранены, их зависимости устанавливаются через `npm ci --include=dev`
в папке backend. Стандартные production-зависимости их не содержат.
Frontend-команды `predev` и `prebuild` синхронизируют оба JSON-файла.

Dockerfile обеих частей использует корень репозитория как контекст:

```sh
docker build -f frontend/Dockerfile -t evrika-frontend .
docker build -f backend/Dockerfile -t evrika-backend .
```

Контейнеры используют Node 22, как проверенное локальное окружение.
Для рабочих листов действует единый лимит файла 12 МБ при скачивании и открытии.

## Обновление зависимостей

Конфигурация SvelteKit 3 находится в `frontend/vite.config.js`, импорты
компонентов используют `#lib/`. Сборки Node, static и Vercel проверяются отдельно.
`npm audit --omit=dev` не находит уязвимостей в обеих частях проекта.
Полный audit frontend пока сообщает о шести low-записях из одной цепочки
`deepmerge` в инструментах сборки: [исправленной версии пока нет](https://github.com/advisories/GHSA-gcqx-w48m-w2h4).
Для `@vercel/nft` задан `glob` 14, чтобы использовать исправленные `glob` и `minimatch`;
локальная Vercel-сборка проверена с этим override.

## Сценарии и задания с пропусками

При открытии рабочего листа можно выбрать чистый лист, сценарий для учеников,
сценарий для учителя, работу с текстом и словами, проверку знаний, чтение или рефлексию.
Сценарий ученика содержит ситуацию, роли, этапы решения и рефлексию. Сценарий
учителя — начало, ОНМ, закрепление, практику и итоги; его страницы явно подписаны.
Все части сценария — обычные редактируемые блоки.

В блоках «Текст с пропусками» и «Допиши слово» выделите текст и нажмите
«Сделать пропуск» либо запишите ответ как `[[слово]]`, включая часть слова,
например `ele[[phant]]`. Слова для справки можно отключить. В версии с ответами
показывается скрытый текст. Маркеры и настройки сохраняются в файле проекта.
В «Соедини пары» левая и правая части вводятся в одной строке; правый столбец
ученической версии переставляется автоматически.

## Иллюстрации приёмов

В семи развёрнутых карточках добавлены пять найденных схем Wikimedia Commons
(одна схема может относиться к нескольким приёмам). Изображения локальные,
не требуют запросов к стороннему серверу и имеют увеличение и подписи RU/UZ/EN.
Язык оригинальных надписей отмечен отдельно. Авторство, ссылки, условия
и сведения об оптимизации: `frontend/static/images/techniques/CREDITS.md`.
